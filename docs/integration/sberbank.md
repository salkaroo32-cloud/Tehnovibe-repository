# Интеграция со Сбербанком — результат проверки T-010

Дата проверки: 2026-09-04

## Итог

В публичной официальной документации Сбера найден отдельный механизм **Сбер ID для физических лиц**, но он предназначен для аутентификации/передачи идентификационных данных, а не для чтения банковских операций.

Официальная документация Sber ID описывает `client_type=PRIVATE` и scopes вроде `openid`, `email`, `mobile`, `name`, `birthdate`, `gender`, `maindoc`, `inn`, `snils` и др. Перечня scope для доступа к выписке личного банковского счёта в этой документации нет.

## Что подтверждено

### 1. Сбер ID для физлиц существует

Sber ID позволяет партнёрскому приложению авторизовать физическое лицо через СберБанк Онлайн/веб-страницу Сбер ID. Для партнёра требуется зарегистрированный `client_id`; доступные scopes выдаются при регистрации системы в Банке.

Это можно использовать в нашем проекте как отдельный слой **идентификации пользователя**, если бот/веб-контур будет зарегистрирован как партнёр Сбера.

### 2. Официальный Sber API умеет отдавать выписку

Sber API имеет методы получения выписки и отдельных операций. Для документированного метода используется `access_token`, `accountNumber`, `statementDate`, `page` и scope `GET_STATEMENT_ACCOUNT`. История через этот канал доступна за предыдущие 5 лет + текущий год; для методов выписки заявлена пропускная способность 5 TPS.

### 3. Но выписка не подтверждена для обычного физлица

Актуальный официальный сценарий Sber API «Выписки по счёту» описывает контур СберБизнес/СберБизнес ID и пользователя из пространства компании. Поэтому нельзя считать, что `GET_STATEMENT_ACCOUNT` можно просто выдать пользователю-физлицу через Сбер ID.

В публичной документации, проверенной в T-010, не найден официальный retail scope вида «доступ к операциям личного счёта физического лица».

## Вывод для MVP

**Отдельный retail-механизм Сбера для авторизации физлица — найден: Сбер ID.**

**Отдельный подтверждённый retail-механизм для чтения операций личного счёта физлица — не найден в публичной документации.**

Поэтому архитектурно разделяем:

`Telegram ID → Sber ID (идентификация/consent)`

и отдельно:

`BankProvider → получение банковских операций`

На данный момент второй контур для физлиц остаётся блокером.

## Что нельзя делать

Не использовать логин/пароль от СберБанк Онлайн, SMS-коды, cookies, reverse engineering или неофициальную автоматизацию для получения выписки. Такие способы не являются подтверждённым официальным API-контуром MVP.
