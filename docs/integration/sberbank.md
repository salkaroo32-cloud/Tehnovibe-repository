# Интеграция со Сбербанком — результат проверки T-010

Дата проверки: 2026-09-04

## Что подтверждено официальной документацией

Sber API содержит методы получения банковской выписки. Для метода получения выписки требуется `access_token`, номер счёта, дата выписки и page; для доступа нужен scope `GET_STATEMENT_ACCOUNT`. Выписка через этот канал доступна за предыдущие 5 лет + текущий год. Для связанных методов заявлена пропускная способность 5 TPS.

## Критическое ограничение для нашего MVP

Актуальная документация описывает данный контур через СберБизнес / СберБизнес ID. В официальном сценарии «Выписки по счету» явно указаны предусловия: пользователь имеет профиль в СберБизнес своей компании, находится в пространстве Платформы и авторизован через СберБизнес ID. Там же пользователь описан как сотрудник компании либо представитель ЮЛ/ИП.

Поэтому найденный Sber API нельзя считать подтверждённым решением для целевого сценария MVP с обычным физическим лицом и его личным счётом. В публичной документации, проверенной в рамках T-010, подтверждения такого retail-сценария не найдено.

## Решение по T-010

- Официальный API выписок существует — **да**.
- Технический контракт выписки и необходимые права для документированного контура — **подтверждены**.
- Поддержка именно физического лица с личным счётом в требуемом MVP-сценарии — **не подтверждена**.
- Поэтому банковский контур MVP остаётся **заблокированным до подтверждения отдельного официального retail-механизма**.

## Что нельзя делать

Не использовать логин/пароль от СберБанк Онлайн, SMS-коды, cookies, reverse engineering или неофициальную автоматизацию. Это не является допустимым способом реализации MVP.
