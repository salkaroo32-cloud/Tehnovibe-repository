# T-020 — Backend Telegram MVP — attempt a02

## Цель
Исправить ошибки обработки PDF-выписки и стабилизировать Telegram-сценарий MVP.

## План попытки
- Проверить текущие `app/bot.py`, `app/analyzer.py`, тесты и workflow.
- Исправить ошибку async/sync при извлечении PDF.
- Улучшить обработку ошибок PDF и HTML-отчёта.
- Добавить регрессионные тесты для структуры Sber-выписки без сохранения пользовательских банковских данных.
- Проверить код локально доступными средствами и зафиксировать ограничения.

## Фактические действия
Начата проверка текущих файлов репозитория. Обнаружена ошибка: `extract_pdf_text` объявлена как async, но передаётся в `asyncio.to_thread`, что приводит к возврату coroutine вместо текста.

## Результат
