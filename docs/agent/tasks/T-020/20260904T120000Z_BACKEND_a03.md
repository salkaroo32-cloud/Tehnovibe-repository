# T-020 attempt a03 — device-aware Sber redirect

## Goal
Add an HTTPS redirect endpoint for the Telegram "Получить выписку" flow that detects Android/iOS from User-Agent and attempts the corresponding Sber app deeplink, with web fallback.

## Actions
- Re-checked official Sber developer documentation for deeplink behavior.
- Confirmed Sber documents SSO deeplinks such as `sberbankonline://sberbankid/sso` and notes that the Sber ID redirect scheme can change; therefore the configured scheme is treated only as best-effort app launch.
- Re-checked Telegram Bot API: inline button `url` accepts HTTP or tg:// URLs, so the bot points to an HTTPS redirect endpoint rather than a custom `sberbankonline://` URL directly.
- Added `aiohttp` dependency.
- Added `app/sber_redirect.py` with Android/iOS/other User-Agent detection, configurable Sber deeplinks, `/sber` redirect page and `/health` endpoint.
- Updated `app/bot.py` so the bank button uses `PUBLIC_BASE_URL/sber` when configured and runs the redirect HTTP server alongside Telegram polling.
- Updated `.env.example` with `PUBLIC_BASE_URL`, `WEB_PORT`, and platform-specific Sber deeplink settings.
- Added `tests/test_sber_redirect.py` covering Android/iOS/other detection and fallback HTML.
- Updated README with deployment and local-run requirements.

## Verification
- Repository changes committed successfully.
- Static test coverage was added for the platform-detection logic.
- Full mobile Telegram/iOS/Android E2E cannot be verified from the current environment because it requires a public HTTPS host and physical client devices.
- Without `PUBLIC_BASE_URL`, the bot intentionally falls back to the existing direct HTTPS Sber URL.

## Safety/limitations
- No Sber credentials, cookies, SMS, reverse engineering, or unofficial API access.
- Sber's documented deeplink is an SSO mechanism; this implementation does not claim to open the personal statement screen automatically.
- The redirect must be exposed through a public HTTPS domain for Telegram users to reach it.
