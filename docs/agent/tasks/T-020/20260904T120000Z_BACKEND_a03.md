# T-020 attempt a03 — device-aware Sber redirect

## Goal
Add an HTTPS redirect endpoint for the Telegram "Получить выписку" flow that detects Android/iOS from User-Agent and attempts the corresponding Sber app deeplink, with web fallback.

## Actions
- Re-checked official Sber developer documentation for deeplink behavior.
- Confirmed Sber documents SSO deeplinks such as `sberbankonline://sberbankid/sso` and notes that the Sber ID redirect scheme can change; therefore no hardcoded Sber ID scheme is treated as a guaranteed universal app-launch URL.
- Re-checked Telegram Bot API: inline button `url` accepts HTTP or tg:// URLs, so the bot should point to an HTTPS redirect endpoint rather than a custom `sberbankonline://` URL directly.
- Plan implementation: aiohttp redirect endpoint, User-Agent detection, Android/iOS-specific configured deep links, HTTPS Sber web fallback, and Telegram button pointing to configured public redirect URL.

## Verification
- Code changes are being applied in this attempt.
- Full mobile Telegram/iOS/Android E2E cannot be verified from the current environment because it requires a public HTTPS host and physical client devices.

## Safety/limitations
- No Sber credentials, cookies, SMS, reverse engineering, or unofficial API access.
- Deep links are configurable and documented as best-effort app launch only; the redirect does not claim to open the personal statement screen.
