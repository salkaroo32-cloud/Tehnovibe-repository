# T-020 — попытка a01

- Владелец: Backend.
- Статус попытки: в работе.
- Цель: собрать первый запускаемый Telegram MVP для загрузки банковской выписки и анализа.
- Основание: пользователь запросил рабочий MVP с `/start`, кнопкой получения выписки, переходом в Сбербанк, ожиданием файла и отчётом после загрузки.
- Разрешённые файлы этой попытки: `app/*`, `tests/*`, `requirements.txt`, `.env.example`, `Dockerfile`, `README.md`, `docs/agent/tasks/T-020/*`.
- Ограничение: прямой retail API Сбербанка для операций физлица ранее не подтверждён; кнопка «Получить выписку» использует официальный веб-вход/интерфейс Сбербанка, после чего пользователь вручную загружает полученную выписку в бот.
- Проверяемые критерии:
  1. `/start` показывает кнопку «Получить выписку».
  2. Кнопка ведёт пользователя на официальный СберБанк Онлайн и переводит диалог в состояние ожидания выписки.
  3. PDF-выписка принимается ботом и обрабатывается без сохранения банковских секретов.
  4. Анализ классифицирует регулярные платежи до определения подписок и формирует понятный отчёт.
  5. Проект содержит инструкции запуска и переменные окружения без секретов в репозитории.
- Прогресс до реализации: 0/5.
- Точный следующий шаг: создать минимальный проект на Python с aiogram, PDF-парсером и детектором регулярных платежей, затем выполнить локальные тесты.
