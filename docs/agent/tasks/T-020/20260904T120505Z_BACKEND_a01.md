# T-020 — попытка a01

- Владелец: Backend.
- Статус попытки: реализовано, локальная runtime-проверка заблокирована отсутствием доступа к PyPI в текущей среде.
- Цель: собрать первый запускаемый Telegram MVP для загрузки банковской выписки и анализа.
- Основание: пользователь запросил рабочий MVP с `/start`, кнопкой получения выписки, переходом в Сбербанк, ожиданием файла и отчётом после загрузки.
- Разрешённые файлы этой попытки: `app/*`, `tests/*`, `requirements.txt`, `.env.example`, `Dockerfile`, `README.md`, `docs/agent/tasks/T-020/*`.

## Выполненные действия

1. Создан `app/bot.py` на aiogram 3: `/start`, кнопка «Получить выписку», переход на официальный URL СберБанк Онлайн, FSM-состояние ожидания PDF, приём файла, временное хранение, удаление файла после анализа и отправка отчёта.
2. Создан `app/analyzer.py`: извлечение операций из текстового PDF, нормализация merchant, отдельный слой классификации регулярных платежей и детектор подписок.
3. Реализована классификация типов: `подписка/сервис`, `банковская комиссия/услуга`, `перевод/финансовая операция`, `регулярный платёж неизвестного типа`, `недостаточно данных`.
4. Добавлены regression-тесты в `tests/test_analyzer.py` для Regular Charge, единичного Yandex Plus и повторяющейся сервисной подписки.
5. Добавлены `Dockerfile`, `.env.example`, обновлённый README и GitHub Actions workflow для `pytest`.
6. Зависимости проверены по PyPI: aiogram 3.31.0 и pypdf 6.14.2 доступны; обе версии поддерживают Python 3.13. В текущей среде установка пакетов не выполнилась из-за отсутствия сетевого доступа к PyPI.

## Результат по критериям

- Критерий 1: **реализован, не runtime-проверен** — `/start` содержит кнопку «Получить выписку».
- Критерий 2: **реализован, не runtime-проверен** — кнопка ведёт на `SBER_ONLINE_URL` и переводит FSM в ожидание выписки.
- Критерий 3: **реализован, не runtime-проверен** — PDF принимается, обрабатывается во временном файле и удаляется; банковские секреты не запрашиваются.
- Критерий 4: **реализован, не runtime-проверен** — классификация выполняется до детектора подписок, отчёт содержит confidence и объяснение.
- Критерий 5: **реализован** — есть README, `.env.example`, Dockerfile и test workflow без секретов.

## Проверка

Попытка локально установить `pypdf` и `pytest` завершилась ошибкой сетевого доступа к PyPI, поэтому полный `pytest` в текущем execution environment не запущен. GitHub Actions workflow добавлен, но доступный коннектор не вернул workflow run для push-коммита; успешность CI поэтому не утверждается.

## Важное ограничение MVP

Прямой retail API Сбербанка для чтения операций физлица ранее не был подтверждён. Поэтому «Получить выписку» открывает официальный онлайн-интерфейс Сбербанка, после чего пользователь вручную отправляет PDF в бот. Автоматический ввод логина/пароля/SMS, cookies и reverse engineering не используются.

## Следующий шаг

Запустить проект с реальным `BOT_TOKEN`, проверить Telegram happy path и прогнать пользовательскую PDF-выписку. После runtime-проверки обновить критерии и при необходимости скорректировать PDF-парсер по реальным форматам Сбера.
