# T-010 — попытка a02

**Статус попытки:** завершена.

## Цель
Проверить по официальной документации Сбера, существует ли технически и юридически пригодный для нашего MVP официальный механизм получения операций обычного физического лица, а также зафиксировать права, формат и ограничения найденного механизма.

## Фактическая проверка
1. Проверена актуальная документация Sber API по выпискам.
2. Подтверждено наличие метода получения выписки по счёту: требуется `access_token`, `accountNumber`, `statementDate`, `page`; для доступа нужен scope `GET_STATEMENT_ACCOUNT`; заявлена история за предыдущие 5 лет + текущий год. Связанные методы выписок имеют лимит 5 TPS.
3. Проверена официальная документация Sber ID. Для партнёров доступна авторизация физических лиц через СберБанк Онлайн/Сбер ID; используется `client_type=PRIVATE`, а scopes включают идентификационные данные (`openid`, `email`, `mobile`, `name` и др.).
4. Проверена официальная документация сценария «Выписки по счёту». В ней явно указаны пользовательский профиль в СберБизнес своей компании, пространство Платформы и авторизация через СберБизнес ID; пользователь описан как сотрудник компании либо представитель ЮЛ/ИП.
5. Сопоставление показало: Sber ID подтверждён как retail-механизм идентификации физлица, но публичный Sber API не подтверждает выдачу через него операций личного банковского счёта физлица.

## Результат по критериям
- Критерий 1: **не выполнен для целевого retail-сценария**. Официальный API выписок найден, но подходящий канал для физического лица не подтверждён.
- Критерий 2: **выполнен для документированного SberBusiness-контура**: права, ограничения и формат результата зафиксированы.
- Критерий 3: **выполнен на уровне MVP-принципов**: detection нужен нормализованный merchant, дата, сумма/валюта, направление и стабильный идентификатор; банковские логины/пароли/SMS-коды хранить нельзя.

## Важное уточнение
Отдельный retail-механизм **Сбер ID** найден, но он решает задачу идентификации пользователя и получения разрешённых идентификационных данных. Это не доказательство доступа к банковской выписке физлица.

## Итог
T-010 не закрывает банковский блок MVP. Текущий результат: **заблокировано, 2/3 критериев**. Нужна дополнительная официальная коммуникация/документация Сбера, подтверждающая именно retail-доступ к операциям физического лица, либо нужно изменить банковский контур MVP.

Не использовать логин/пароль от СберБанк Онлайн, SMS-коды, cookies, reverse engineering или неофициальную автоматизацию.
