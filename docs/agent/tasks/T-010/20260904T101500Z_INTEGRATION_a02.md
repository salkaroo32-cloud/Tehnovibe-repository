# T-010 — попытка a02

**Статус попытки:** начата до внесения изменений.

## Цель
Проверить по официальной документации Сбера, существует ли технически и юридически пригодный для нашего MVP официальный механизм получения операций обычного физического лица, а также зафиксировать права, формат и ограничения найденного механизма.

## План проверки
1. Проверить актуальную документацию Sber API по выпискам.
2. Проверить модель авторизации, scope и тип пользователя/счёта в официальном сценарии.
3. Сопоставить найденный механизм с целевым сценарием MVP: Telegram-пользователь → свой личный счёт Сбера → чтение операций.

Результаты будут дописаны в этот файл после проверки.
